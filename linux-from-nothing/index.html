Linux From Nothing

Budowa niezależnego systemu operacyjnego od zera. Pełna kontrola nad toolchainem, kompilacją jądra i przestrzenią użytkownika.

Repozytorium Odkryj architekturę ↓
Kernel Configuration

Architektura systemu

[*] KONTROLA

Budowa od podstaw

Wszystkie pliki binarne, biblioteki oraz skrypty rozruchowe są kompilowane ręcznie – bez gotowców.

[*] TOOLCHAIN

Niezależny zestaw narzędzi

Kompilacja własnego łańcucha narzędziowego (Binutils, GCC, Glibc) gwarantuje pełną izolację.

[*] KERNEL

Jądro monolityczne

Kompilacja jądra Linux dostosowanego architekturą i parametrami pod konkretny sprzęt docelowy.

Assumptions

Założenia techniczne

──

Brak menedżera pakietów

System nie opiera się na żadnej istniejącej dystrybucji. Całość powstaje wyłącznie ze źródeł.

──

Minimalna przestrzeń użytkownika

Środowisko bazuje na okrojonym zestawie `coreutils` w celu zachowania niewielkiego rozmiaru obrazu.

──

Własny init

System uruchamiany jest przez autorski skrypt inicjalizacyjny, który można łatwo modyfikować.
