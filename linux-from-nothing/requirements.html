// REQUIREMENTS

System Requirements

01

Operating System

Linux distribution (or Windows WSL) with GCC, make, autoconf, and automake installed.

02

Hardware

Minimum 4GB RAM (8GB recommended) and approximately 10GB of free disk space for builds.

03

Network

Stable internet connection to fetch all required upstream source packages and patches.
