System Requirements

01

Minimal (To boot the system)

  • CPU: Any 64-bit processor (Intel Core 2 Duo, AMD Athlon X2 or newer).
  • RAM: 512 MB – 1 GB (A clean terminal consumes very little, but Archiso requires some RAM to load the squashfs filesystem).
  • Minimal disk space: Approximately 5–10 GB
  • GPU: Any graphics card capable of displaying text on the screen (even integrated onboard graphics).
02

Recommended (For comfortable compilation)

  • CPU: Multi-core (e.g., Intel Core i5 / AMD Ryzen or better) – more cores mean faster compilation (e.g., using make -j$(nproc)).
  • RAM: 4 GB or more (Compiling large programs can heavily strain memory).
  • Storage: 10–20 GB of free space on an SSD (Compilation generates a lot of temporary files, and an SSD drastically speeds up write times).
  • Internet: Stable network connection (wired Ethernet or Wi-Fi) for downloading clean source code.
